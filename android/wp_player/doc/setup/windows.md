# Toolkit

1. CMake - [CMake](https://cmake.org/)
2. Ninja (somewhat optional but recommended) - [Ninja](https://ninja-build.org/) (if used check how to setup generator for CMake via environment variables or via CLI flags)
3. MinGW - there are several options, you can check them out at [MinGW-w64.org](https://www.mingw-w64.org/downloads/), but as recommendation (if you use Windows) check [Prebuilt MinGW toolchain](https://winlibs.com/) (maybe also check more full toolchains - where LLVM/Clang/LLD/LLDB are included)

# Main idea
Due to flutter [restriction/build choice] - window version is builded leveraging [MSVC](https://visualstudio.microsoft.com/vs/features/cplusplus/). Yet there is problems with native lib (at least currently) - cause MSVC dropped support to some C atomic library, that might (in sense that it is at least included) be used in miniaudio (also maybe some other problems).

To make this work the next setup might be thought of - cause native_library is used as dynamically linked lib in flutter, it might be possible to compile it before compilation of native part by flutter framework and just be copied alongside .exe that is generated by flutter (don't forget that by utilizing MinGW you access additional *.dll*s that might not be present on user machine - so you also need to provide this *.dll*s along side provided .dll of native_lib).

# About Dart SDK
To make callbacks from native library NativePort from Dart SDK is leveraged. You may consider to update Dart SDK (just delete old code and put new Dart SDK - you may found it somewhere like SOME_PATH/Flutter/bin/cache/dart-sdk, you need to copy only include dir (and rename it to just lib when to put inside native_library))

# Preparing
Currently system is already prepared but in case of updating native code, tools or any other reason of recompiling .dll you need to

0. Make any changes that would result in need of recompiling, etc.
1. Make default compilation with CMake+Ninja+MinGW of native library (checkout on internet how it is done)
2. Put newly compiled .dll into windows subfolder (where old one was)
3. Don't forget also adding any .dll required by usage of MinGW (to check what .dll are required, you may look into `objdump` from MinGW toolchains or similar)
4. Recompile flutter app

> > **Note:** try to think ahead about possible clutter due to configuration/compilation to not add work for yourself (maybe copy native_library source code to some temp file and config/compile there)
